# assets de la demo Flashlight (Linterna de casco)

Reusados de `demo_holoterminal/assets/` (Paso 12), que a su vez los copió del repo
de Odisea (**solo lectura**):

- `HoloScreen.shader`: copia de `Odisea_Game/src/core_v2/visual/HoloScreen.shader`
  con los uniforms del cursor por shader (`cursor_uv`, `cursor_size_uv`,
  `cursor_tex`). No se modifica Odisea.
- `Silkscreen-Regular.ttf`: fuente Silkscreen, copiada de
  `Odisea_Game/src/assets/fonts/Silkscreen-Regular.ttf`. No había archivo de
  licencia OFL al lado; el origen es el proyecto Google Fonts
  (https://github.com/google/fonts/tree/main/ofl/silkscreen), licencia
  SIL Open Font License 1.1 (OFL-1.1).

# Shared Operator Instructions

## Workflow

- `AGENTS.md` (repo root) is the canonical, harness-neutral instruction file and stays authoritative for workflow, rules, testing, deploy and style. Do not duplicate its rules here.

## Private / Shared Policy

- Shared (committed): durable project docs — specs (`specs/SPEC-*.md`), how-to guides (`guides/`), `/polish` session logs (`sessions/YYYY-MM-DD_<tema>.md`), plans (`plans/`, incl. `tech-debt.md`), Kilo briefs (`briefs/`).
- New specs keep the `SPEC-<area>.md` name; code comments cite specs by bare filename, so never rename a spec without updating those comments.
- Spanish is the language of shared docs, matching `AGENTS.md`.
